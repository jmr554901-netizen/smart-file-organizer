SMART FILE ORGANIZER
=====================
1. ABOUT THE PROJECT
--------------------
Smart File Organizer is a simple Python desktop application that
helps organize files into separate folders such as Images, Documents,
Videos, Music and Others.
2. TECHNOLOGY USED
------------------
Python
Tkinter
os module
shutil module
3. PROJECT FILES
----------------
main.py
Starts the application.
ui.py
Contains the Tkinter graphical user interface.
organizer.py
Contains the main file-organizing logic.
categories.py
Contains the file extensions used for each category.
utils.py
Contains small helper functions and file statistics.
4. HOW TO RUN
-------------
1. Make sure Python is installed.
2. Keep all project files in the same folder.
3. Open a terminal in the project folder.
4. Run:
python main.py
5. HOW IT WORKS
---------------
1. Open the program.
2. Click Select Folder.
3. Choose a folder containing files.
4. Check the displayed statistics.
5. Click Organize Files.
6. The program creates category folders and moves files into them.
6. PYTHON CONCEPTS USED
-----------------------
- Variables
- Functions
- if/else statements
- for loops
- Lists
- Dictionaries
- Modules and imports
- Exception handling
- File and folder handling
7. IMPORTANT NOTE
-----------------
The program does not overwrite a file if a file with the same name
already exists in the destination folder.
This project does not use a database, JSON, API, HTML, CSS or JavaScript.
